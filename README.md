# Maruey Book Buddy

###### โปรแกรมแนะนำหนังสือจากห้องสมุดมารวยให้เหมาะสมกับแต่ละบุคคล โดยใช้อายุ ความสนใจ ประสบการณ์ ภูมิหลังความรู้ ของแต่ละบุคคลเป็นข้อมูลสำหรับแนะนำหนังสือ โดยแนะนำหนังสือจากที่ให้บริการใน www.maruey.com ให้แสดงผลความยากง่ายของหนังสือ แนะนำหนังสือใหม่ แต่ก็สามารถแนะนำหนังสือเก่าที่ classic หรือเป็นที่นิยมได้เช่นกัน และแสดงผลเป็นชื่อหนังสือ เรื่องย่อ และสถานะหนังสือตามสถานะที่ระบุในหน้าเว็บ เช่น พร้อมให้บริการ ถูกยืม หากมีคำแนะนำที่เป็นประโยชน์ที่ได้จาก website ที่น่าเชื่อถืออื่นๆ ระบุเป็นหมายเหตุได้ โดยให้รองรับการทำงานทั้ง Desktop และ Mobile ให้ถาม Yes/No Question พร้อมข้อเสนอ เพื่อให้เข้าใจ Requirement ชัดเจนที่สุด
